# **App Name**: TradeSage

## Core Features:

- AI Trade Analysis: AI-powered bot providing real-time analysis using news feeds as a tool for buy/sell recommendations.
- Live Charting: Real-time charting using live market data for clear and concise visualization of crypto and forex price movements.
- Dashboard: Intuitive dashboard showing recent trades, open positions, and account balance for quick performance monitoring.
- Watchlist: Watchlist where users can tag favorite crypto and forex pairs.

## Style Guidelines:

- Primary color: Strong blue (#3F51B5) to evoke trust and reliability.
- Background color: Deep navy (#1A237E) for a professional and sophisticated feel.
- Accent color: Bright cyan (#00BCD4) for call-to-action buttons and important information highlights.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and easily readable interface.
- Sharp, modern icons for crypto/forex indicators. Use a consistent line weight and style across all icons.
- Use a grid-based layout to ensure content is well-organized, easy to scan, and visually appealing.
- Subtle animations, like micro-interactions on button hover, loading sequences, and chart updates to add polish and feedback.
